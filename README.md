# Merchant Pro 商用照片排版打印工具

Merchant Pro 是一个面向照相馆、文印店和活动现场打印场景的照片排版打印工具。核心流程是：

```text
导入照片 -> 自动排版 -> 预览校验 -> 加入队列 -> 批量打印
```

工具重点解决商用打印中常见的问题：照片比例不一致、社交平台方图容易被裁切、批量任务需要提前预览、打印前需要检查位置和纸张规格。

## 运行环境

- 系统：Windows
- Python：建议使用 3.12 x64，与 Windows 便携版构建环境一致
- 主要依赖：
  - `Pillow`
  - `pywin32`，用于直接提交 Windows 打印任务
  - `tkinterdnd2`，可选，用于拖拽导入

在仓库根目录打开 PowerShell，安装依赖并启动程序。

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe .\photo_layout_printer.py
```

也可以双击：

```text
启动照片排版工具.bat
```

## 构建 Windows 便携版

在已创建上述虚拟环境的 Windows x64 电脑上运行：

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements-build.txt
.\.venv\Scripts\python.exe -m PyInstaller portable.spec
```

将整个 `dist\照片排版工具_Win10-11_64位` 文件夹复制到目标电脑，保留其中的 `_internal` 目录，双击 `照片排版工具.exe` 启动。目标电脑需要安装对应打印机的 Windows 驱动。要沿用同一台电脑已有的校准，先退出程序，再将旧版 EXE 旁的 `photo_layout_config.json` 复制到新版 EXE 旁。

## 界面结构

当前界面按商户工作台组织为三块：

- 左侧：批量导入、批次预览选择、打印勾选和检查
- 中间：版面预览和素材托盘
- 右侧：排版与打印设置、照片微调、打印范围

顶部工具栏提供高频入口：

- 载入演示照片
- 多照片拼版
- 清空队列
- 打印预览页
- 高级校准

## 打印规格

“纸张与照片规格”只保留一个下拉菜单，当前支持：

| 模板 | 相纸方向 | 用途 |
| --- | --- | --- |
| `5寸整张` | 竖向，单张整纸 | 标准 5 寸整张照片 |
| `5寸+3寸` | 竖向，上下双张 | 5 寸相纸切成两张 3 寸照片 |
| `6寸整张` | 竖向，单张整纸 | 标准 6 寸整张照片 |
| `6寸+4寸` | 竖向，上下双张 | 6 寸相纸切成两张 4 寸照片 |
| `6寸左右双栏` | 横向，左右双栏 | 更适合手机竖图和社交平台照片 |

规格摘要不放在左侧参数区，而是显示在中间预览画布右上角，包括相纸尺寸、单张槽位、排版方向、中缝、输出像素、DPI 和照片适配模式。

## 照片适配模式

照片适配用于处理原图比例和照片槽位比例不一致的问题。

| 模式 | 说明 | 适合场景 |
| --- | --- | --- |
| `裁切填满` | 普通照片裁切填满槽位；检测到 1:1 方图时会自动保护，避免暴力裁掉人物 | 传统相机图、构图空间足够的照片 |
| `适应留白` | 保留完整画面，不裁切，多余区域留白 | 合照、客户要求不能裁切的照片 |
| `等边裁切` | 保持比例并居中裁切至同样宽度的四边留白，方图也按此处理 | 需要裁完四边相等的成品 |
| `原始像素优先` | 大图等比缩小，小图保留原始像素，多余空间留白 | 小尺寸素材、避免放大 |
| `拍立得风` | 方图自动做拍立得式留白 | 社交平台方图、拍立得风产品 |

## 批量导入逻辑

批量导入时，系统会按当前模板决定每个批次需要几张照片：

- `5寸整张` / `6寸整张`：每 1 张照片生成 1 个打印批次
- 拼版模板：每 2 张照片生成 1 个打印批次

如果当前是两张拼版模板，并且导入照片数量是单数，最后一张会弹出处理选择：

- 第二格留空
- 从列表中重选一张
- 重新上传一张
- 取消最后一组

每个常规批次保存源照片、旋转、边距、适配模式和输出图。点击左侧某一组，下方“照片 1 / 照片 2”会切换到该组。旋转和单张位置微调只更新当前组，操作后仍停留在该组。

边部留白、照片适配等统一排版设置会一次更新队列中的全部常规照片组，无需逐组修改；各组源照片、手动旋转和打印勾选分别保留。打印勾选只决定哪些页提交打印，不限制统一设置的应用范围。多照片拼版使用其独立编辑窗口中的设置。

## 打印前检查

左侧“打印前检查”会检查：

- 队列是否为空
- 每个批次是否有足够照片
- 成片像素是否匹配当前模板
- 照片框是否超出相纸
- 照片内容是否超出照片框
- 中缝和边距是否被自动限幅

“打印勾选页”和“打印全部”都会再次校验本次要打印的页，并检查驱动报告的纸张规格。

## 选择部分相纸打印

例如使用“6寸+4寸”批量导入六张照片，左侧会生成三页相纸。勾选第 1、3 页后，点“打印勾选页（2）”只提交这两页。点击缩略图可以翻看其他页，勾选范围仍然保留。“打印全部”提交整个队列。遇到不同尺寸的相纸时，按队列顺序分组，在切换时提示换纸。

## 多照片拼版

点“多照片拼版”，选择 5 寸、6 寸、7 寸、8 寸或 A4，再选左右双拼、上下双拼、四宫格、两种六宫格或九宫格。导入后可调整顺序、翻页和设置留白，照片排满后自动另起一页，最后的空格会显示在预览中。点击加入队列后，可用同一套勾选和打印操作。

需要裁成四边等宽的照片时，选“等边裁切”，启用边部留白并保持照片居中。设有额外中缝的上下或左右双拼要沿两条线剪去中间的纸条。保留完整构图和拍立得效果的模式会产生额外留白。窗口缩放只改变屏幕预览的大小。

例如“五寸+三寸”模板，边部留白设为 3.0 mm、中缝设为 0 时，每张照片四边各约 3 mm；整纸中间是上下两张照片的白边相加，合计约 6 mm。批量导入后把留白改成 3.0 mm，会同步更新全部常规照片组，无需逐组删除后重新加入。毫米转换为像素有不到一像素的取整差异。

## 打印方式

### 在软件内保存打印机页面设置

在打印机列表下点击“打印机页面设置…”，核对当前打印机、纸张规格和横竖方向，然后点击“设置页面布局并保存…”。软件会打开这台打印机提供的完整设置窗口，可选普通尺寸、无边距、扩展量、纸张类型、质量等。各打印机提供的选项不同。

在打印机窗口点击“确定”后，本软件保存该次设置，并自动切换为“默认直接打印”。后续同一电脑、同一打印机、同一纸张和方向会直接载入，不用每次重新设置。横向与纵向、不同纸张分别保存；打印机别名不影响对应关系。设置只保存在本软件中，不修改 Windows 的全局打印默认值。

取消窗口不改动原设置；“恢复此纸型默认设置”只清除当前对应记录。更换驱动版本后如果旧设置不能兼容，会提示重新保存。更换电脑时不会套用另一台电脑的驱动参数。

需要临时变更时，仍可选择“使用系统打印设置”。系统窗口的临时修改只作用于本次打印；要长期保存，请使用“打印机页面设置…”入口。

Canon G500 使用薄白边时，可以选择无边距并把“扩展量”拉到最左端，再保存。佳能说明这个位置按全尺寸输出。软件设置等边裁切、边部留白 3.5 mm、中缝 0 时，两张相邻白边合计约 7 mm。首次仍需实物校验尺寸，应用生成的版面校验不能证明所有驱动的私有缩放都已关闭。[佳能 G500 无边距与扩展量说明](https://ij.manual.canon/ij/webmanual/PrinterDriver/W/G500%20series/1.0/SC/PPG/dg-c_borderless.html)

新电脑默认跟随 Windows 默认打印机。直接打印前，程序会重新获取当前设备，向它的驱动查询纸型、方向和可打印区域。同一版面可以换到另一台支持该纸张的 Windows 打印机。正常匹配后即可打印，只有需要修正实际出纸偏差时才用高级校准。

要固定一台设备，从“打印机”列表中手动选择即可。重新勾选“跟随 Windows 默认打印机”可恢复自动选择。若固定的设备已被移除，程序会提示重新连接或改选。不同电脑分别保存设备选择。

同一台电脑连接多台打印机时，可逐台从列表选中并点“命名”，例如命名为“前台相片机”或“后室相片机”。列表同时显示自定义名称和 Windows 打印机名。名称在本机的本工具中使用，重新打开后仍有效。再次点“命名”可以修改，留空保存即可恢复系统名称。

右侧“打印方式”提供两种输出模式：

- 默认直接打印：不弹出系统打印窗口，软件直接按当前打印机、相纸尺寸、方向和打印画面微调提交任务。
- 使用系统打印设置：提交前打开 Windows 系统打印对话框，适合临时确认纸张类型、方向或驱动选项。

默认推荐使用“默认直接打印”。如果更换纸张类型或驱动设置不确定，可以临时切到“使用系统打印设置”。

“相纸放置方向”可选自动（跟随版面）、纵向（短边在上）、横向（长边在上）。正式照片和校准测试共用这个选择，修改后预览同步更新。程序只整页旋转，不重新排列、拉伸或修改队列中原有照片。实际进纸方式仍按打印机纸盒要求放置。驱动返回的方向与所选方向不同时，会在打印前列出请求和实际方向供核对。

## 单独打印

顶部“打印预览页”打印当前看到的页。选中队列批次时，使用该批次最新编辑后的版面。

单独打印也会走同一套校验和 Windows 打印管线，不会绕过位置检查。

## 高级校准

顶部点击“高级校准”会打开二级页面。这里放低频但重要的打印机校准项：

- 整张画面左右微调
- 整张画面上下微调
- 重置打印画面微调
- 中缝留白
- 启用边部留白
- 智能横竖旋转
- 预览安全线
- 打印裁切标记

这些设置会影响预览、校验和实际打印位置。建议只在更换打印机、纸张、驱动或发现打印偏移时调整。

## 中心十字校准图

高级校准页面中有“打印中心十字校准图”按钮。它只打印校准图，不打印照片，也不会加入批量队列。

校准图包含：

- 纸张外框
- 纸张物理中心红色十字
- 加长红色十字与延伸至四边的蓝色主轴，毫米刻度延伸到纸边附近；打印机硬边距外的末端可能不出墨，图中毫米刻度保持原尺寸
- 横向和纵向 1mm 刻度
- 5mm 加长刻度
- 10mm 数字标注
- 距纸边 10mm 的参考框
- 20mm 校验尺和 10×10mm 方框，用于检查缩放或单轴拉伸
- 相纸宽高、纵横方向、图示上边箭头、DPI 和当前打印补偿值

校准窗口右侧实时显示测试图，左侧可切换相纸方向。该选择也会用于正式照片打印。纵横方向分别读取和保存补偿。窗口大小只影响屏幕显示，校准图始终以真实毫米刻度、100% 比例提交打印。

校准建议流程：

1. 选中需要校准的打印机，点击队列中要打印的那张相纸的缩略图。没有队列预览时，会使用主窗口的纸张规格。
2. 打开“高级校准”，核对窗口显示的打印机、纸张宽高、方向和 DPI。打印机和相纸规格使用窗口打开时的目标，包括 7 寸、8 寸和 A4 拼版；纵横方向可以在窗口内切换。
3. 点击“打印中心十字校准图”。
4. 先用尺子确认 20mm 校验尺和 10×10mm 方框的实际尺寸，再测十字中心到左右、上下纸边的距离。
5. 水平偏移＝（左距－右距）÷2，垂直偏移＝（上距－下距）÷2。新的补偿＝当前补偿－测得偏移。例如向右偏 2mm，就把“整张画面左右微调”减少 2mm；向下偏 1mm，就把上下微调减少 1mm。
6. 再次打印校准图，直到中心十字对齐。

## 注意事项

- 打印前请确认右侧选择的打印机正确。
- 选中要试打的缩略图，再点右侧“检查本页打印定位”，可以不耗纸地读取该次驱动实际报告的纸张尺寸、四边硬边距和预计缩放。使用系统打印设置时，在对话框确认后会显示诊断结果。
- 佳能 G580 使用 G500 驱动时，按实际相纸选择纸型。需要薄白边可采用上文的“无边距＋扩展量最左端”；采用“普通尺寸”时应考虑硬边距，可先用 6 mm 等边留白进行对照。普通打印时，G580 非方形相纸的左右硬边距为 3.4 mm，上为 3 mm，下为 5 mm。具体放置以该次打印的驱动报告值为准。[佳能 G580 规格](https://www.canon.com.cn/product/g580/spec.html) · [佳能 G500 页面设置](https://ij.manual.canon/ij/webmanual/PrinterDriver/W/G500%20series/1.0/SC/PPG/Dg-pagesetup.html)
- 如果照片超出可打印范围，确认窗口会列出必要的缩小比例。若须保持指定尺寸，可取消，增大留白后重新生成该页。人工校准按打印机、纸张宽高和方向保存。同一台打印机的同规格、同方向相纸可以在双拼、四宫格等排列之间共用校准值；旧版保存的模板偏移仍可读取。
- 直接打印会自动初始化相纸尺寸和方向；系统打印设置模式下仍建议在对话框中确认纸张规格。
- 如果驱动页面尺寸和目标相纸差异过大，软件会阻止提交打印。
- 批量打印不会使用单张快速推送逻辑，而是按队列统一提交。
- 当前工具以直接打印为主，不把导出功能作为主路径。

## 开发检查

修改代码后可先检查所有模块的语法：

```powershell
python -m compileall -q .\photo_layout_printer.py .\photo_layout
python -m unittest discover -s tests -v
```

再启动程序，检查照片导入、各纸张模板、适配模式、批次预览和打印前校验。实际打印还需要使用连接的打印机检查。
